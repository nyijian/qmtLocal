# 03 脚本清单

所有命令都在项目根目录 `D:\QuantStock\qmtLocal` 下执行。

**图例**　🟢 不需要 QMT　🟡 需要大QMT 开着且桥接服务在运行　🔵 在大QMT 里面运行

## tools/ 本地命令行工具

| 脚本 | 做什么 | 环境 | 依赖 |
|---|---|---|---|
| `market_overview.py` | A股大盘快照：指数、涨跌家数、涨跌停/炸板、涨跌幅分布、成交额和量比、站上均线比例、申万一级行业强弱、自动解读 | `.venv313` | 🟡 实时；`--offline` 时 🟢 |
| `tick_subscribe.py` | 订阅实时 tick 并打印；可按持仓自动订阅 | 任一 | 🟡 只在交易时段有推送 |
| `trade_monitor.py` | 打印资金、持仓、委托、成交；`--watch` 持续盯变化。只读不下单 | 任一 | 🟡 账号读 `.env` |
| `local_history.py` | 读 QMT 本地日线缓存；`--gaps` 看哪些代码滞后该补 | 任一 | 🟢 |
| `fetch_akshare.py` | 用 akshare 下载财务（四张表）、龙虎榜（个股明细、机构席位、活跃营业部）、两融汇总和个股明细到共享数据目录（OneDrive）的 `akshare/`，增量更新 | **只能 `.venv313`** | 🟢 要联网 |

```powershell
.venv313\Scripts\python.exe tools\market_overview.py              # 实时
.venv313\Scripts\python.exe tools\market_overview.py --offline    # 只读本地缓存
.venv313\Scripts\python.exe tools\market_overview.py --top 8      # 行业前后各 8 名

.venv\Scripts\python.exe tools\tick_subscribe.py 000001.SZ 600000.SH --snapshot
.venv\Scripts\python.exe tools\tick_subscribe.py --positions      # 订阅当前持仓

.venv\Scripts\python.exe tools\trade_monitor.py                   # 快照一次
.venv\Scripts\python.exe tools\trade_monitor.py --watch           # 持续盯

.venv\Scripts\python.exe tools\local_history.py --gaps
.venv\Scripts\python.exe tools\local_history.py 000300.SH -n 20

.venv313\Scripts\python.exe tools\fetch_akshare.py                  # 三类都下；重跑只补缺的
.venv313\Scripts\python.exe tools\fetch_akshare.py lhb margin       # 只下其中几类
.venv313\Scripts\python.exe tools\fetch_akshare.py margin --detail-years 5   # 两融明细也要 5 年
```

**默认年限**：财务、龙虎榜、两融汇总 5 年（`--years`）；两融个股明细 3 年（`--detail-years`，一天一次请求，深交所还要放慢）。

`fetch_akshare.py` 的输出目录结构、增量规则写在脚本开头的注释里。首次全量约 2 小时（两融个股明细逐日下载占大头），
之后每天跑一次只要一两分钟。读回 CSV 时股票代码要用 `dtype=str`，否则前导 0 会丢。

## strategies/ QMT 策略

🔵 最终在大QMT 里运行；本地用 `qmt_mock` 假运行（🟢，`.venv`）。

| 脚本 | 说明 |
|---|---|
| `双均线示例.py` | 快慢均线金叉买、死叉卖的示例策略 |
| `test1.py` | 试 `get_market_data_ex` 取数的练习脚本 |

```powershell
.venv\Scripts\python.exe -m qmt_mock.runner strategies\双均线示例.py --code 600000.SH --start 20240101 --end 20240301 --seed 42
```

输出太长时，同时存一份到日志，方便在编辑器里翻（`logs/` 不进 git）：

```powershell
.venv\Scripts\python.exe -m qmt_mock.runner strategies\test1.py --code 600000.SH --start 20240101 --end 20240301 | Tee-Object -FilePath logs\run.log
```

参数说明见 [qmt_mock/README.md](../qmt_mock/README.md)。

## qmt_client_scripts/ QMT 里的常驻脚本

🔵 粘贴进大QMT「策略编辑器」运行，本地跑不了。

| 脚本 | 说明 |
|---|---|
| `桥接服务.py` | 桥的服务端，监听 58611。挂法见 [01-环境搭建](01-环境搭建.md#4-在大qmt-里挂桥接服务)。关键开关：`ALLOW_ORDER`（默认 False）、`PASSORDER_ARGS`、`TRADE_POLL_INTERVAL` |
| `提取财务数据.py` | 用 `ContextInfo.get_financial_data` 读 QMT 本地财务库，导出 `real_data/financial_data.csv`。改 `STOCK_LIST` / `FIELD_LIST` 后运行 |

## tests/ 自测

| 脚本 | 测什么 | 依赖 |
|---|---|---|
| `桥接自测.py` | 用假 ContextInfo 和假柜台把桥的协议端到端走一遍，不碰真实账号 | 🟢 几秒 |
| `桥接压测.py` | 背压、多客户端、并发、大 payload、异常恢复；改了桥的线程/队列/连接逻辑后跑 | 🟢 十几秒 |
| `dat读取自测.py` | .DAT 格式解析 + 本机真实数据的一致性抽查 | 🟢 |
| `dotenv自测.py` | `.env` 解析和加载 | 🟢 |

```powershell
.venv\Scripts\python.exe tests\桥接自测.py
```

最后一行 `FAILURES: 0` 才算过。
